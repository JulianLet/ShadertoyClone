# Shadertoy Clone

This is the final project for my **Realtime Graphics course**. The project allowed me to learn about **shader programming** and how to create a real-time rendering environment.

## Features

- Similar setup as [Shadertoy](https://www.shadertoy.com)  
- Create and test your own custom shaders  
- Interactive environment to experiment with visual effects  

## Tech / Tools Used

- Visual Studio 2022 (C++)
- HLSL / GLSL Shaders
- Real-time rendering techniques

## Learning Outcomes

- Understanding of **shader programming pipelines**  
- Handling real-time graphics and GPU computation  
- Working with **external shader code** and integrating it into your engine  

## How to Run

1. Open the solution in Visual Studio 2022  
2. Build the project (ignore `.vs` cache / intermediate files)  
3. Run the executable and experiment with shaders
